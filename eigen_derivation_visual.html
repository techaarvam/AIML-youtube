Deriving Eigenvalues And Eigenvectors From A v = λ v

Step-By-Step Derivation

Matrix A

[ 2 1 ]
[ 1 1 ]

Diagonal Λ

[ λ₁ 0 ]
[ 0 λ₂ ]

1. Start With The Eigenvalue Condition

A v = λ v

[ 2  1 ] [ x ]   =   λ [ x ]
[ 1  1 ] [ y ]       [ y ]

2. Move Everything To One Side

(A - λI) v = 0

[ 2-λ   1   ] [ x ] = [ 0 ]
[  1   1-λ ] [ y ]   [ 0 ]

For a nonzero vector v, this system must be singular.

3. Characteristic Equation

det(A - λI) = 0

(2-λ)(1-λ) - 1 = 0
λ² - 3λ + 1 = 0

4. Solve For The Eigenvalues

λ = (3 ± √5)/2

λ₁ = (3 + √5)/2 ≈ 2.618
λ₂ = (3 - √5)/2 ≈ 0.382

5. Solve For Each Eigenvector

For λ₁:
(2-λ₁)x + y = 0  ⇒  y = (λ₁ - 2)x
Take x = 1  ⇒  v₁ = [ 1, λ₁ - 2 ]

For λ₂:
(2-λ₂)x + y = 0  ⇒  y = (λ₂ - 2)x
Take x = 1  ⇒  v₂ = [ 1, λ₂ - 2 ]

6. Interpretation

A v₁ = λ₁ v₁
A v₂ = λ₂ v₂

Each eigenvector is a direction preserved by the matrix. The action of A scales that direction by the corresponding eigenvalue.
